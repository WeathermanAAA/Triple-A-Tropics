How to read these maps

Actual shows each grid cell's sea-surface temperature on the latest analysis day, colored from violet (cold, 0 °C) through blue, green, yellow, orange, and red (warm, 32 °C). Contour lines run at each integer degree for easy reference.

Anomaly shows how today's SST compares to the 1991–2020 mean for this same day of year. Red / magenta tones mark areas warmer than average; blue / purple mark cooler. Scale runs from −5 °C to +5 °C; values beyond saturate at the extremes.

Anomaly + Records overlays diagonal hatching and a black outline on the anomaly map where today's SST is the warmest or coldest ever observed for this day of year since OISST records began in 1982. The underlying color tells you the direction: red-hatched = record high, blue-hatched = record low.

Data source

All fields come from NOAA's Optimum Interpolation Sea-Surface Temperature (OISST) v2.1 daily analysis — a 0.25° global grid merging AVHRR satellite observations, ship + buoy reports, and Argo floats. OISST has roughly a one-day latency; these maps refresh once per day at 13:00 UTC.
