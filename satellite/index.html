Latest polar pass (250 m photographic)

The Latest Polar Pass panel above is a daily, high-resolution photographic snapshot per region — NASA's MODIS (Terra/Aqua, ~250 m) and VIIRS (SNPP/NOAA-20, ~375 m) true-color corrected-reflectance composites, served via NASA GIBS. Unlike the geostationary tool above, polar-orbiting sensors image each spot once or twice a day, so this is the freshest complete daily pass — gaps between orbit swaths are filled across sensors. Pick a region from the dropdown; the caption shows which sensor and day you're seeing.

How it works

Pick a bbox by dragging a rectangle on the map (the rectangle tool is the topmost button on the left toolbar). Choose a channel — IR Channel 13 for nighttime convection, upper-level water vapor for steering, or visible for daytime detail — and an enhancement preset. Hit Render and the backend crops a tile just for your bbox and returns it as a PNG.

Any bbox size works — the backend picks the smallest GOES product family that covers your box (a Mesoscale sector if it fits in a ~12°×12° window, then CONUS, then Full Disk) so the source resolution is as fine as possible, and auto-downsamples oversized requests to stay within a 16M-pixel render budget. When that kicks in you'll see an "auto-downsampled" note on the result. Identical re-requests come back from cache instantly. Rate limit: 10 renders / minute / IP.

Coverage

Three satellite families today: GOES-East (currently GOES-19, with the GOES-16 archive back to 2017) covers ~135°W to 5°W — the Atlantic basin, eastern Pacific, and the Americas. GOES-West (currently GOES-18, with the GOES-17 archive back to 2019-02-12) covers ~160°E to ~-65°W via the antimeridian — Hawaii, Alaska, central + eastern Pacific. Himawari-Pacific (Himawari-9 since 2022-12-13, with the Himawari-8 archive back to 2017) covers ~60°E to 220°E — Western Pacific, East Asia, Oceania. The picker auto-routes by bbox center, so any zoom in any basin works without picking a satellite by hand. METEOSAT (Atlantic east / Africa / Europe) is next on the roadmap, along with full-disk presets, named-region floaters, and live storm-centered floaters.
