Fleet health

Every render box publishes a heartbeat to R2 once a minute. The box asserts liveness itself, independently of whether its lanes produced a frame — so a dead box reads as dead here instead of merely looking like a quiet basin on the imagery pages. Freshness is judged on the heartbeat's own timestamp: a stale file means a dead box no matter how healthy its contents look.

The roster on this page is published from fleet.yml in tat-satellite-render, so a new box appears here as soon as it is in the inventory — nothing to edit in the site repo. scripts/fleet.sh status|drift|deploy is the operator side. A box showing “no heartbeat” is in the inventory but has never published: check its timer with systemctl status tat-heartbeat.timer.
