Fleet health

Every render box publishes a heartbeat to R2 once a minute. The box asserts liveness itself, independently of whether its lanes produced a frame — so a dead box reads as dead here instead of merely looking like a quiet basin on the imagery pages. Freshness is judged on the heartbeat's own timestamp: a stale file means a dead box no matter how healthy its contents look.

Inventory and the lane→box assignment map live in fleet.yml in tat-satellite-render; scripts/fleet.sh status|drift|deploy is the operator side of this page. A box missing from this grid entirely has never published — check that its heartbeat timer is installed (fleet.sh provision <box>).
